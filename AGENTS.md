# AGENTS.md

This file provides guidance to AI coding agents working with code in this repository.

## Overview

Design Angular Kit is an Angular 21+ component library implementing [Bootstrap Italia](https://italia.github.io/bootstrap-italia/) for Italian Public Administration web applications. The repo contains two distinct projects:

- **`projects/design-angular-kit/`** — the publishable library (`design-angular-kit` on NPM)
- **`src/`** — the documentation/demo app (nunjucks + compodoc + Angular)

## Commands

```bash
# Install dependencies
npm i

# Start documentation app (compiles nunjucks + compodoc, then serves)
npm run start

# Build documentation app
npm run build

# Build the library only
npm run build:lib

# Watch-build the library (development, no docs)
npm run watch:lib

# Run library unit tests (Vitest via Angular unit-test builder, single run)
npm run test

# Run schematics tests separately (these still use Jasmine + ts-node)
npm run schematics:test

# Lint
npm run lint
npm run lint:fix       # auto-fix ESLint issues
npm run lint:format    # auto-format with Prettier
```

To run a single spec file, use the Angular CLI directly:
```bash
npx ng test design-angular-kit --no-watch --include='**/accordion/**/*.spec.ts'
```

## Architecture

### Library structure (`projects/design-angular-kit/src/lib/`)

Components are organized into three groups, mirroring the module:

| Folder | Contents |
|--------|----------|
| `components/core/` | UI components (accordion, alert, avatar, badge, button, card, carousel, chip, collapse, dimmer, dropdown, list, modal, notifications, pagination, popover, progress-bar, spinner, steppers, tab, table, timeline, tooltip, video-player, …) |
| `components/form/` | Form controls (autocomplete, checkbox, input, password-input, radio-button, range, rating, search, select, textarea, transfer, upload-*) |
| `components/navigation/` | Navigation (back-button, back-to-top, breadcrumbs, footer, header, megamenu, navbar, navscroll, sidebar, skiplink) |
| `components/utils/` | Utility components (error-page, icon, language-switcher) |
| `abstracts/` | Base classes all components inherit from |
| `enums/` | `ColorsEnum`, `SizesEnum` — used as typed `@Input` values across components |
| `services/` | `NotificationService` |
| `pipes/` | `ItDateAgoPipe`, `ItDurationPipe`, `ItMarkMatchingTextPipe` |
| `validators/` | `ItValidators` (Italian-specific: tax code, IBAN, VAT, plates, etc.) |
| `interfaces/` | Shared TypeScript interfaces and `DesignAngularKitConfig` |
| `utils/` | Coercion helpers, date/file utils, regex constants |

The library also ships an `ng-add` schematic (`projects/design-angular-kit/schematics/ng-add/`) that automates installation setup.

The public API is `projects/design-angular-kit/src/public_api.ts`.

### Abstract base classes

**`ItAbstractComponent`** (`abstracts/abstract.component.ts`) — base for all components. Injects `Renderer2`, `ElementRef`, and `ChangeDetectorRef`. Automatically generates unique kebab-case IDs and emits `valueChanges` on any `@Input` change. Declared with `standalone: false`; concrete subclasses must explicitly set `standalone: true`.

**`ItAbstractFormComponent<T>`** (`abstracts/abstract-form.component.ts`) — extends `ItAbstractComponent`, implements `ControlValueAccessor`. Provides `validationMode`, `isValid`/`isInvalid` getters, `invalidMessage` via `TranslateService`, and auto-enables `validationMode` when the control is inside a `FormGroup`.

### Component conventions

- All selectors are prefixed `it-` (e.g. `it-accordion`, `it-input`)
- All components are **standalone** (can be imported individually), but are also exported via `DesignAngularKitModule` for module-based apps
- Components with sub-parts are grouped in a `*.module.ts` (e.g. `ItAvatarModule`, `ItCarouselModule`)
- `@Input({ transform: inputToBoolean })` is used for boolean inputs

### Initialization

Library consumers call either `provideDesignAngularKit(config?)` (standalone/functional) or `DesignAngularKitModule.forRoot(config?)`. These providers configure:
- Bootstrap Italia asset path (`IT_ASSET_BASE_PATH` injection token)
- Font loading via `bootstrap-italia`'s `loadFonts()`
- `@ngx-translate` with Italian i18n from `{assetBasePath}/i18n/`
- `provideAnimationsAsync()` and `provideHttpClient()`

### Documentation app (`src/`)

- Routes live in `src/app/app-routing.module.ts` with one module per component category
- HTML pages are generated from Nunjucks templates (`*.tpl` files, compiled by `npm run nunjucks-compile`)
- API docs are generated by compodoc from the library's `tsconfig.lib.json`

### Testing

Library and app unit tests run on Vitest through the `@angular/build:unit-test` builder (`runner: vitest`; the app project also uses `src/test-setup.ts`). Schematics specs are the exception: they run with Jasmine via `npm run schematics:test`. Import `tb_base` from `projects/design-angular-kit/src/test.ts` as the `TestBed.configureTestingModule` config — it sets up `provideRouter([])`, `TranslateModule.forRoot()`, and the `IT_ASSET_BASE_PATH` token.

```typescript
import { tb_base } from '../../../../test';
await TestBed.configureTestingModule(tb_base).compileComponents();
```

## Commit conventions

Commits are enforced by commitlint (Conventional Commits). Pre-commit hooks auto-run `lint:fix` and `lint:format` via lint-staged.

**Important distinction:**
- `fix`, `feat`, `BREAKING CHANGE` — **library changes only** (trigger semver bump and changelog)
- `docs` — documentation or comment changes (**do not** trigger versioning); can include a scope to clarify intent, e.g. `docs(fix): fixed button example`
- `build`, `ci`, `perf`, `refactor`, `style`, `test`, `chore` — other changes

Branch naming convention: `feature/##-descrizione-issue` (where `##` is the issue number).
